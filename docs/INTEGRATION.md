# Интеграция компонентов

Команды установки и запуска находятся в [README проекта](../README.md). Все три процесса запускаются из корня одного проекта.

| Компонент | Назначение | Адрес по умолчанию |
| --- | --- | --- |
| FastAPI | Объекты, загрузка файлов и выдача результатов | `127.0.0.1:8000` |
| Воркер | Очередь фотографий, YOLO и AI-сводки | Отдельный процесс без HTTP-порта |
| Node.js | Интерфейс и прокси `/api/v1` | `127.0.0.1:4173` |

`API_TARGET` задаёт адрес бэкенда для прокси фронтенда. API и воркер должны использовать одинаковые `.env` и `STORAGE_DIR`. По умолчанию хранилище — `.local/material-backend/`; настройки из окружения имеют приоритет над `.env`.

## Подключение интерфейса

В «Подключение и профиль» выберите «Настоящий API /api/v1». Интерфейс читает `/api/v1/meta` и запрашивает только поддерживаемые функции.

- `scope: inspection`: объекты, снимки, материалы, готовность, ручные проверки, история и стоимость постройки.
- `gigachat_analysis` — отдельная возможность; она не включает полный банковский дирижёр.
- Риск, задачи, тревоги, освоение участка, акты и импорт реестра в реальном API пока отключены.
- Режим «Демо» в браузере использует синтетические сценарии. `MOCK=1` на сервере проверяет загрузку и очередь, но не распознаёт фотографии.

## Результаты обработки

Детектор вызывается один раз на снимок. Классификатор использует найденные стены. Поле `result` облёта содержит готовность, `material_result` — материал. Ручные проверки разделены: `readiness_review` и `material_review`; совместимое `review` относится к готовности.

В стеновых наблюдениях `conf` — уверенность детектора, `material_conf` — уверенность классификатора. Имена классов берутся из весов; числовые номера классификатора не заменяют справочник материалов.

Ракурсы могут определяться по EXIF; проверьте, что рассчитанные стороны соответствуют съёмке. Выделение области дома помогает исключать соседей и не заменяет проверку кадастровой принадлежности.

## Настройки и изменения

После замены весов перезапустите воркер; после изменения `.env` или правил — API и воркер. Старые облёты автоматически не пересчитываются. Для проверки новых весов загрузите новый облёт.

После изменения тарифов в `configs/valuation.yaml` обновите снимок для деморежима:

```powershell
python -m scripts.export_valuation_demo
```
