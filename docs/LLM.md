# Подключение AI через OpenAI-совместимый API

Бэкенд использует библиотеку `openai` и метод `chat.completions.create`. Адрес сервера, API-ключ и модель задаются в `.env`. Один клиент подходит для DeepSeek, Qwen в Alibaba Cloud Model Studio и других серверов с совместимым Chat Completions API, включая локальные Ollama/vLLM/LM Studio.

Имя библиотеки не определяет получателя данных: запросы отправляются только по `LLM_BASE_URL`. Без явно заданного адреса и модели интеграция не включается. Ключ OpenAI для Qwen или DeepSeek не нужен — нужен ключ выбранного сервиса.

## Настройка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-backend.txt
```

Общие переменные в `.env`:

```dotenv
MOCK=0
LLM_ENABLED=1
LLM_API_KEY=ключ_выбранного_провайдера
LLM_BASE_URL=адрес_из_кабинета_провайдера
LLM_MODEL=имя_доступной_модели
LLM_JSON_MODE=json_object
LLM_TIMEOUT_SECONDS=60
LLM_MAX_TOKENS=1200
LLM_TOKEN_LIMIT_FIELD=max_tokens
LLM_AUTO_ANALYZE=1
LLM_EXTRA_BODY_JSON={}
```

`LLM_BASE_URL` — корень API, без `/chat/completions`. Сохраняйте требуемый провайдером префикс `/v1` или `/compatible-mode/v1`. Используйте HTTPS; HTTP допускается только для локального сервера на `localhost` или loopback IP. Параметры URL и авторизация в URL запрещены. TLS проверяется стандартными средствами Python.

### Пример DeepSeek

```dotenv
LLM_BASE_URL=https://api.deepseek.com
LLM_MODEL=deepseek-flash
LLM_JSON_MODE=json_object
LLM_EXTRA_BODY_JSON='{"thinking":{"type":"disabled"}}'
```

Имя модели проверяйте по своему аккаунту и актуальной документации. Отключение thinking подходит для короткой сводки и позволяет не расходовать небольшой лимит ответа на рассуждения. JSON-режим требует инструкции JSON в промпте; клиент добавляет схему и пример ответа сам. [Документация DeepSeek: JSON Output](https://api-docs.deepseek.com/guides/json_mode/), [параметры Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/).

### Пример Qwen / Alibaba Cloud Model Studio

Скопируйте точный адрес и идентификатор модели из рабочего пространства. Пример для пространства в Сингапуре:

```dotenv
LLM_BASE_URL=https://ВАШ_WORKSPACE_ID.ap-southeast-1.maas.aliyuncs.com/compatible-mode/v1
LLM_MODEL=qwen-plus
LLM_JSON_MODE=json_object
LLM_EXTRA_BODY_JSON='{"enable_thinking":false}'
```

Регион ключа должен соответствовать региону API. `enable_thinking` зависит от выбранной модели: если она не поддерживает этот параметр, оставьте `{}`. Не используйте регион или workspace из примера буквально. [Официальная настройка OpenAI-совместимого Qwen API](https://www.alibabacloud.com/help/en/model-studio/compatibility-of-openai-with-dashscope).

Для локального сервера укажите его OpenAI-совместимый адрес, установленную модель и непустой ключ (например, `local`, если сервер не требует авторизации).

## Формат ответа и совместимость

| Переменная | Назначение |
| --- | --- |
| `LLM_JSON_MODE=json_object` | Общий JSON-режим для совместимых моделей; схема проверяется бэкендом |
| `LLM_JSON_MODE=json_schema` | Строгая схема в `response_format.json_schema`; только если модель поддерживает |
| `LLM_JSON_MODE=text` | Не передавать `response_format`, просить JSON промптом; проверка остаётся обязательной |
| `LLM_TOKEN_LIMIT_FIELD` | `max_tokens` по умолчанию; `max_completion_tokens` для API, которые требуют это имя |
| `LLM_EXTRA_BODY_JSON` | Дополнительные параметры провайдера; не могут менять модель, сообщения, формат ответа или включать инструменты/поток |

Универсальность означает общий поддерживаемый протокол, а не одинаковые возможности всех моделей. Если получен HTTP 400, проверьте имя модели, JSON-режим и дополнительные параметры. Клиент не переключает платного провайдера автоматически и не повторяет запросы скрыто. После смены провайдера уберите параметры, относящиеся к предыдущему.

Для OpenAI-совместимого сервера доступны настройки адреса и транспорта в [официальной документации OpenAI SDK](https://developers.openai.com/api/reference/python). Формат `response_format` описан в [Chat Completions](https://developers.openai.com/api/reference/python/resources/chat/subresources/completions/methods/create).

## Проверка

Перезапустите API и воркер, чтобы оба прочитали новые настройки:

```powershell
.\.venv\Scripts\python.exe -m integrations.llm --check
```

Команда делает только `GET /models`, без генерации. Код завершения: `0` — выбранная модель есть в списке; `1` — ошибка или модели нет; `2` — отключено, деморежим или неполные/некорректные настройки. Некоторые серверы не реализуют список моделей: неуспешная проверка списка сама по себе не проверяет генерацию. Команда не выводит ключ или содержимое ошибок провайдера.

Для проверки генерации откройте объект в интерфейсе и нажмите **«Обновить AI-сводку»**. Либо выполните `POST /api/v1/objects/{id}/analysis` с телом `{}`, затем проверяйте `GET /api/v1/objects/{id}/analysis`. Работает отдельный воркер `python -m worker`. Статус подключения без сетевого запроса: `GET /api/v1/llm/status`. Признак поддержки в `/meta`: `capabilities.llm_analysis`.

## Что происходит с данными

1. YOLO анализирует фотографии локально, бэкенд считает готовность и стоимость.
2. В очередь попадает снимок подготовленных фактов, правил и допустимых шагов.
3. Воркер передаёт в AI только эти факты: фотографии, адрес, кадастровый номер, данные клиента и свободные комментарии не отправляются.
4. Бэкенд проверяет JSON, ссылки на факты и допустимость рекомендаций. Ответ, обрезанный по лимиту токенов, отказ или пустой ответ не принимается.
5. Интерфейс показывает проверенную сводку (`decision_source: llm`) либо вывод по правилам (`rules_fallback`). Действия подтверждает сотрудник.

Очередь и аудит сохраняются в SQLite. Изменение фактов, адреса API, модели или параметров генерации делает прежнее заключение устаревшим; история сохраняется. Замена ключа не меняет факты. При смене настроек нажмите «Обновить AI-сводку»; массовый платный пересчёт сам не запускается.

При `MOCK=1`, `LLM_ENABLED=0` или отсутствии ключа/адреса/модели внешние запросы не выполняются. Ошибки авторизации, квоты, лимитов, тайм-ауты и недоступность API дают безопасный вывод по правилам. Секреты хранятся только в `.env` на сервере, не в браузере и не в Git.
