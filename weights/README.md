# Обученные модели

Положите сюда файлы, полученные от ML-команды:

```text
weights/
├── readiness_yolo26m.pt
└── material_yolo26m-cls.pt
```

Файлы весов исключены из Git. Настройки подключения приведены в [README проекта](../README.md), формат вызова и классы — в [инструкции YOLO](../docs/YOLO_INTEGRATION.md).

После замены весов перезапустите воркер. Проверяйте новую версию новым облётом: сохранённые результаты автоматически не пересчитываются.
