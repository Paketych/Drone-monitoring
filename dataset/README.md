# Исходные фотографии

Папки с идентификаторами объектов содержат оригиналы снимков. Сервис сохраняет загруженные копии в `.local/` и не изменяет эти исходники.

- Список снимков, объектов, ракурсов и статусов проверки — [manifest.csv](../ml/annotations/manifest.csv).
- Рамки и материалы стен — [ml/annotations/labels/](../ml/annotations/labels/).
- Подготовка датасета и обучение — [инструкция ML](../ml/README.md).

Разметка и оригиналы хранятся отдельно. Для обучения исходный файл должен существовать по пути из реестра; одна запись в CSV не заменяет фотографию. Внешние исходники могут находиться в `data/external/`, который исключён из Git.

Снимки одного дома, включая разные облёты и вырезки стен, следует относить к одной выборке при проверке качества.
